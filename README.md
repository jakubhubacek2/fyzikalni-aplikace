# Fyzikální aplikace

Interaktivní výukové aplikace pro fyziku a elektrotechniku. Web je publikován pomocí GitHub Pages.

Veřejný rozcestník: **<https://jakubhubacek2.github.io/fyzikalni-aplikace/>**

## Fyzika (6 aplikací)

- [Převody jednotek A–E](https://jakubhubacek2.github.io/fyzikalni-aplikace/prevody-jednotek-trenazer.html) – pět rovnocenných sad, generátor písemek, opravovací režim a místní export výsledků.
- [Fyzika START](https://jakubhubacek2.github.io/fyzikalni-aplikace/fyzika-start-jednotky.html) – úvod do fyziky, veličiny, jednotky SI a převody.
- [Plyn pod lupou](https://jakubhubacek2.github.io/fyzikalni-aplikace/idealni-plyn.html) – stavová rovnice, děje v ideálním plynu a tepelné motory (2 × 45 minut).
- [Uvnitř atomu](https://jakubhubacek2.github.io/fyzikalni-aplikace/atomova-fyzika.html) – modely atomu, kvantová čísla, světlo, spektra a laser (2. ročník, 2 × 45 minut).
- [Za hranicí klasiky](https://jakubhubacek2.github.io/fyzikalni-aplikace/relativisticka-dynamika.html) – relativistická dynamika, hmotnost a energie (2. ročník, 45 minut).
- [Vrh šikmý – badatelna](https://jakubhubacek2.github.io/fyzikalni-aplikace/vrh-sikmy-badatelna.html) – simulace a měření dosahu.

## Elektrotechnika (3 aplikace)

- [Elektrostart](https://jakubhubacek2.github.io/fyzikalni-aplikace/uvod-do-elektrotechniky.html) – úvod do elektrotechniky.
- [Kirchhoffova dílna](https://jakubhubacek2.github.io/fyzikalni-aplikace/kirchhoffova-dilna.html).
- [Trenažér rezistorů](https://jakubhubacek2.github.io/fyzikalni-aplikace/trenazer-rezistoru.html).

## Publikování

GitHub Pages publikuje větev `main`, složku `docs/`. Každá aplikace má vlastní HTML soubor; po přidání nové aplikace je potřeba doplnit její kartu a počty v `docs/index.html` a odkaz v tomto přehledu.
