# Fyzikální aplikace

Interaktivní výukové aplikace pro fyziku a elektrotechniku. Web je publikován pomocí GitHub Pages.

## Aplikace

- Převody jednotek A–E – pět rovnocenných sad, generátor písemek, opravovací režim a místní export výsledků
- Plyn pod lupou – stavová rovnice, děje v ideálním plynu a tepelné motory (2 × 45 minut; samostatně v `docs/idealni-plyn.html`)
- Kirchhoffova dílna
- Trenažér rezistorů
- Vrh šikmý – badatelna
- Elektrostart – úvod do elektrotechniky

Publikovaná verze: <https://jakubhubacek2.github.io/fyzikalni-aplikace/>
